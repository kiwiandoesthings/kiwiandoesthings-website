Ao3 Proxy

This page allows you to search for stories on Ao3 to get the story ID of the one you are looking for. Using that story ID, you can then also view story texts on this page.

A Small Warning

This viewer is very basic. If a story uses advanced html or images (idk if ao3 can even do that) it may not display correctly. However, most stories, even those utilizing text formatting, should work pretty fine.
